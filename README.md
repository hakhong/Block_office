## 프로젝트 개요

Block Office는 30명 안팎의 기술 회사의 하루를 3D로 들여다보는 웹 시뮬레이션입니다.
직원 27명이 각자의 팀·성별·흡연 여부·일과표를 가지고 움직입니다.
누가 어디서 무엇을 하는지는 실시간 현황판과 카운터로 집계됩니다.

- **보는 재미**: 전경, 3인칭, 1인칭, 다른 직원의 시점으로 사무실을 둘러봅니다.
- **사는 재미**: 내 캐릭터로 직접 걸어 다니며 자리에 앉고 화이트보드에 글을 씁니다. 면접자가 되어 볼 수도 있습니다.
- **세는 재미**: 화장실, 옥상, 업무시간, 대표 호출, 회의 참석을 사람별로 기록합니다.
- **실험해 보는 재미**: Three.js를 공부하려고 만든 프로젝트입니다. 실제 사람과 실시간으로 연동되지는 않고, 모든 직원은 시뮬레이션으로 움직입니다.

설치나 빌드 없이 [데모 페이지](https://hakhong.github.io/Block_office/)에서 바로 실행하거나, `index.html` 파일 하나를 브라우저로 열면 됩니다.

## 주요 기능

### 🏢 공간
| 구역 | 내용 |
|---|---|
| 북쪽 | 대표실, 경영지원팀, 창가 핫데스크(모니터 1대) |
| 팀 사무실 | 개발팀, 디자인팀, 사업팀 (팀별 고정석, 개인 칸막이 자리) |
| 회의실 | 대회의실(롤스크린과 빔 프로젝터), 회의실 B, 회의실 C (화이트보드) |
| 화장실 | 남/녀 분리. 칸막이 문(잠그면 빨간불), 소변기, 세면대. 한 칸에 한 명만 들어갑니다 |
| 1층 공용 | 서버실, 라운지, 카페(바리스타 상주) |
| 남쪽 신관 | 로비와 안내 데스크, A/S 센터, 하드웨어팀(위) · **공용 랩실**(가운데) · 임베디드팀(아래) |
| 동쪽 별관 | 공용 휴게실 겸 **게임존**(PS5·Xbox·VR, 안마의자), **여성 전용 휴게실**(눕는 소파) |
| 옥상 | 흡연 구역, 벤치, 전망 자리, 가로등 |

### ⏰ 하루 일과 (실제 시각 연동)
- 기본은 **현재 실제 시각**을 따릅니다.
- 장면 버튼(출근·업무 집중·점심·회의·퇴근)을 누르면 가짜 시각으로 그 장면부터 볼 수 있습니다.

| 시간 | 일과 |
|---|---|
| 08:30~09:00 | 가방(백팩, 토트, 서류가방, 숄더백)을 메고 출근합니다. 자리에 오면 사물함부터 정리하고 앉습니다 |
| 09:00~10:00 | 업무 집중 시간. 정말 급할 때 말고는 자리를 지킵니다 |
| 10시, 15시 무렵 | 커피 타임. 카페에서 사서 자기 자리로 들고 와 마십니다 |
| 12:00~13:00 | 점심. 외출, 카페, 회의실 도시락, 자기 자리 중 하나를 고릅니다. 밥을 먹고 나면 게임존에서 놀거나, 여성 휴게실 소파나 책상에 엎드려 낮잠을 잡니다. 바리스타는 여성 휴게실에서 쉽니다 |
| 13:05 | 개발팀·디자인팀 회의. 같은 시각에 대표가 팀장을 소집해 대회의실에서 임원 회의를 엽니다 |
| 14:00 | 하드웨어·임베디드 합동 회의 (회의실 B, 팀장 포함) |
| 18:00 | 대부분 정시 퇴근합니다. `야근` 버튼을 누르면 몇 명이 남습니다 |

### 🖥 개인 자리
- 팀 사무실 책상은 한 사람당 2칸 너비이고, 앞쪽과 양옆이 블라인드(가림막)로 둘러싸여 있어 옆사람이 내 모니터를 볼 수 없습니다.
- 책상 가운데에 듀얼 모니터, 키보드, 마우스가 있습니다. 왼쪽에는 책꽂이, 오른쪽에는 필기도구 통과 필통, 앞에는 종이가 놓여 있습니다.
- 왼쪽 칸막이 아래에 서랍형 사물함이 있습니다. 출근할 때와 근무 중에 가끔 서서 서랍을 열고 정리합니다.
- 가방은 책상 위에 두는 사람도, 책상 아래 바닥에 두는 사람도 있습니다.
- 사람마다 책상 상태가 다릅니다.
  - 정리 성향: 아주 깔끔 / 보통 / 아주 지저분
  - 개인 소품: 가습기, 미니 선풍기, 피규어, 헤드폰, 달력, 화분, 액자, 텀블러
  - 꾸미기 좋아하는 사람은 인형을 줄 세우고 칸막이에 스티커와 사진을 붙입니다.
- 하드웨어팀 책상에는 파워서플라이와 여러 디바이스가, 임베디드팀 책상에는 개발보드와 디버거가 있습니다.

### 🔧 공용 랩실 (하드웨어팀·임베디드팀)
- 남쪽 신관 동쪽 블록은 위가 하드웨어팀, 가운데가 공용 랩실, 아래가 임베디드팀입니다. 두 팀 사이 벽을 허물어 랩으로 만들었고, 위·아래 양쪽에 문이 두 개씩 있습니다.
- 랩 가운데에 **긴 실험 테이블**(가운데는 직사각형, 양 끝은 반원, 정전기 방지 매트)이 있고, 양쪽 5자리씩 공용 장비를 놓았습니다.
  - 오실로스코프: 측정 중 파형이 움직입니다.
  - **TRACE32** 디버거와 타깃 보드, 노트북
  - 납땜 스테이션 2곳: 각각 흡입 후드 → 덕트 → 외벽 배기팬 → 건물 밖 배기구로 이어집니다.
  - 전동 드라이버(충전 거치대 포함)와 나사 트레이, 기구 조립 자리 2곳
  - 계측기: 파워서플라이, 함수발생기, 스펙트럼 분석기
  - 임베디드 보드 디버깅 세트, 회로도와 보드 리뷰 자리
  - 가운데 공용 멀티탭과 부품함
- **온도·습도 챔버**: 시험 중에는 −40°C / 85%RH와 RUN이 뜹니다.
- 공기청정기와 부품 선반도 있습니다.
- 현황판에는 오실로스코프 측정, TRACE32 디버깅, 납땜 중, 계측 장비 측정, 보드 디버깅, 보드 리뷰, 기구 조립, 챔버 시험으로 표시됩니다.

### 🎮 복지: 게임존 (점심시간 전용)
- PS5와 Xbox가 TV, 빈백 2개씩과 함께 있고, VR 플레이 공간이 2자리 있습니다.
- 앉으면 TV에 게임 화면(레이싱, 슈팅)이 켜집니다.
- 12:00~13:00에만 쓸 수 있습니다. 시간 밖에는 들어가지 못하고, 13시가 되면 자동으로 일어납니다.

### 🙋 방문객과 면접
- 방문객이 1~5명씩 무작위로 찾아옵니다. 안내 데스크에서 접수한 뒤 A/S, 미팅, 카페, 화장실을 들르고 돌아갑니다.
- 안내 직원은 손님이 없을 때 앉아서 노트북을 보다가, 손님이 접수하러 오면 일어나서 맞습니다.
- **면접 모드**에서는 내가 지원자가 되어 정문으로 들어와 리셉션에서 접수합니다. 이어서 인사 담당이 마중 나오고, 개발팀장 2명과 실무자가 함께 회의실로 이동합니다. 면접 대화는 자막으로 진행되고, 끝나면 정문까지 배웅합니다.

### 🌦 옥상 전용 날씨
- 맑음, 비, 눈을 고를 수 있습니다.
- 시각에 따라 옥상 바닥 색이 낮 → 노을 → 밤으로 바뀌고, 밤이 되면 가로등이 켜지며 바닥에 불빛이 번집니다.
- 옥상 가장자리는 테두리 벽 없이 트여 보이지만, 끝으로는 걸어 나갈 수 없습니다.
- 흡연 구역 나무 파고라 맨 위(서까래 위)에만 유리 지붕을 얹어, 비와 눈은 유리 위에서 멈춥니다.
- 실내에는 영향을 주지 않습니다.
- `옥상 숨김` 버튼이나 `H` 키로 옥상을 숨기면 1층을 가리는 게 없어집니다.

### 📊 카운터 (오른쪽 패널)
| 탭 | 집계 내용 |
|---|---|
| 현황 | 팀별 직원 상태 (업무 중, 회의, 화장실, 흡연, 낮잠, 게임, 납땜 등) |
| 화장실 | 사람별 이용 횟수, 체류 시간, 손씻기 여부, 흡연 횟수 |
| 옥상 | 옥상 방문 횟수, 체류 시간, 흡연과 바람 쐬기 구분 |
| 업무·회의 | 총 업무시간, 대표 호출 횟수, 회의 참석 횟수, 회의 기록(시각, 종류, 회의실, 인원, 참석자) |

### 🪑 디테일
- 자리에 앉으면 의자를 책상 쪽으로 당겨 키보드에 손이 닿습니다.
- 화장실 문은 기본으로 닫혀 있고, 사람이 손잡이를 잡고 열고 들어갑니다.
- 화분은 통로와 출입구를 피해 방 구석에만 있고, 관엽수, 꽃, 선인장, 몬스테라, 튤립, 라벤더, 귤나무 등 종류가 다양합니다.
- 남녀 헤어스타일이 다르고, 사람이 많은 통로에서는 서로 비켜 지나갑니다.
- 회의실 화이트보드에 직접 글을 쓸 수 있고, 내용은 브라우저에 저장됩니다.
- 단축키는 한글 입력 상태에서도 동작합니다.

## 조작법

| 입력 | 동작 |
|---|---|
| `W` `A` `S` `D` | 걷기 (`Shift` 달리기, `Space` 점프) |
| 우클릭 드래그 / 휠 | 시점 회전 / 거리 조절 |
| `V` | 전경 → 3인칭 → 1인칭 전환 |
| `H` / `옥상 숨김` 버튼 | 옥상(2층) 숨기기 / 보이기 (어느 시점에서나) |
| `E` | 근처 자리에 앉기 / 일어나기 |
| 바닥·자리 클릭 | 그 위치로 이동 |
| 화이트보드 클릭 | 회의실 보드에 글쓰기 |
| 직원 목록 클릭 | 그 사람 시점으로 보기 (`C` 내 시점으로 돌아오기) |

## 실행 방법

```bash
git clone https://github.com/hakhong/block-office.git
cd block-office
# 그냥 열기
open index.html                   # macOS
start index.html                  # Windows
# 또는 로컬 서버
python3 -m http.server 8000       # → http://localhost:8000/
```

> Three.js(r128)를 cdnjs에서 불러오므로 첫 실행 때 인터넷 연결이 필요합니다.

## 기술 스택

- **Three.js r128**: 렌더링, 그림자, 캔버스 텍스처(바닥, 모니터, 화이트보드, 빔 영상, 이름표)
- **Vanilla JS, HTML, CSS**: 프레임워크나 빌드 도구 없이 단일 파일로 구성
- **타일맵 기반 월드**: 문자열 맵(`#` 벽, `c` 책상 의자, `m` 회의 의자 등)으로 층을 정의
- **A\* 길찾기**: 계단 링크와 화장실 칸 출입 방향 제약 포함
- **상태 머신 AI**: 직원마다 일과표, 생리 욕구(화장실, 흡연), 활동 상태를 가집니다
